# Security Policy

## Supported Versions

Only the latest stable release of GymMane Scanner
receives security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities
through public GitHub issues.

Instead, use GitHub's private vulnerability
reporting feature in the Security tab.

Please include:

- Affected app version
- Description of the vulnerability
- Steps to reproduce
- Potential impact

Do not include personal data or sensitive credentials.

This project is maintained voluntarily. Reports will
be reviewed as soon as reasonably possible.

Thank you for helping keep GymMane Scanner secure.
