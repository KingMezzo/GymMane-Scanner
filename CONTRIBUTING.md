# Contributing

Everyone is welcome to contribute to GymMane Scanner!

Whether it's a bug fix, a new feature, a translation
or just an idea, your contribution is appreciated.

## Getting Started

- Fork the repository.
- Open the project in Android Studio or something else.
- Make your changes in a new branch.
- Open a pull request.

GitHub Actions will automatically check your changes.

Feel free to open an issue if you have any questions
or want to discuss an idea.

Thanks for contributing! ❤️
